# My Telegram Mods

Коллекция моих пользовательских модулей для Telegram (Teagram / Telectron).

## Установка
Скопируйте ссылку на файл `my_mod.py` из этого репозитория и загрузите его в свой клиент.

## Команды
- `.ping` — проверить скорость отклика.
- `.say <текст>` — отправить сообщение от вашего имени.
